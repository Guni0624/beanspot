4. 문제와 해결 과정
   - 문제: 폰에서 카카오 로그인 → "잘못된 요청 (KOE205)"
     원인: Supabase가 카카오에 닉네임·프로필 사진·이메일을 같이 요청하는데, 동의항목에 닉네임만 켜져 있었음
     해결: 프로필 사진·이메일을 "선택 동의"로 켬. 이메일은 "권한 없음"이라 개인 개발자 비즈 앱 전환 후 켬
   - 문제: Supabase에서 카카오를 켰는데 서버가 계속 "꺼짐"
     원인: Kakao 창에서 Save를 안 누름 → 해결: 저장 후 ENABLED 확인
   - 문제: 가입 직후 바로 하트를 누르면 로그인 화면이 다시 뜸
     원인: 닉네임을 불러오기 전에 화면으로 돌아감 → 해결: 로그인 정보를 다 불러온 뒤 돌아가게 고침
   - 문제: 시험용 웹 서버가 예전 코드를 보여 줌
     원인: 전에 켜 둔 서버가 꺼지지 않고 남아 있었음 → 해결: 끄고 새로 켬
   - 시험 못 한 것: 카페 등록 끝까지(웹에서는 지도가 안 떠서) → 폰에서 확인 필요

5. 오늘 배운 개념 (용어 정리)
   - Supabase: 로그인·정보 저장·사진 보관을 맡아 주는 서버 서비스 (무료 요금제로 시작)
   - 표(테이블): 엑셀 시트처럼 정보를 줄과 칸으로 보관하는 곳
   - SQL: 서버에 "이런 표를 만들어 줘"라고 시키는 글
   - RLS(지키는 규칙): 누가 어떤 줄을 보고 쓸 수 있는지 정하는 규칙. 공개 키로는 이 규칙 안에서만 됨
   - 공개 키(publishable) vs 비밀 키(secret): 공개 키는 앱에 넣어도 되고, 비밀 키는 절대 앱에 넣으면 안 됨
   - OAuth(카카오 로그인): 카카오가 "이 사람 맞아요"라고 확인해 주고 앱은 그 확인만 받는 방식
   - 동의항목: 카카오 로그인할 때 사용자에게 "이 정보 줘도 돼요?" 묻는 항목
   - 비즈 앱: 카카오에서 이메일 같은 정보를 받으려면 필요한 앱 등급 (개인 개발자도 본인 인증으로 무료 전환)
   - 개발 빌드: 폰에 까는 "만드는 중인 빈스팟 앱". 새 부품(로그인 저장소 등)이 들어가면 다시 만들어야 함
   - 공공데이터 "소상공인 상가(상권) 정보": 나라가 무료로 공개하는 전국 가게 목록(이름·주소·위치·업종)

6. 자주 쓸 명령어
   - npx expo start : 앱 켜기 (r 키 = 폰 앱 새로고침)
   - npx tsc --noEmit : 코드 글자 실수(타입) 검사
   - npx expo install 부품이름 : Expo 버전에 맞는 부품 설치
   - eas build --profile development --platform android : 폰용 개발 앱 만들기
