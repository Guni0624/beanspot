1. 작업 흐름
   ① 지도에 카페 넣는 방법 회의 (스레드 "지도에 카페 등록 방법 정하기")
      - 결정: 카페를 먼저 한꺼번에 넣어 두고, 사진·후기를 하나씩 쌓는 방식
      - 대량 입력 = 공공데이터 "소상공인 상가(상권)정보"(data.go.kr) 카페 업종
      - 카카오 로컬 검색 결과는 우리 서버에 저장 금지(카카오 규칙) → 등록 화면 실시간 검색·장소 ID 연결에만 사용
      - 지역: 고양시 1,954곳 + 파주시 1,099곳 = 3,053곳
      - 상태: 기본(공공데이터, 작은 회색 핀, 바로 공개) / 검토 대기(사용자 새 등록, 구니 승인 필요)
              / 인증(사진 3장 + 후기 1개 모이면 자동) / 숨김(폐업 등)
      - 등록 순서: 이름 입력 → 빈스팟에서 먼저 찾기 → 없으면 카카오 검색 → 사진·한줄 소개 → 검토 대기
   ② 지도 핀 (구니 승인)
      - 빈스팟 로고 동그라미 말풍선 핀(카카오맵 스타일). 꼬리 끝이 정확한 위치
      - 확대 단계: 가까이 = 모든 이름 / 조금 멀리 = 인증 카페 이름만 / 더 멀리 = 핀만 / 아주 멀리 = 숫자 묶음
   ③ 위치가 틀린 카페 (조사 → 해결)
      - 공공데이터 좌표는 "도로명주소 대표 점"이라 아파트 상가·큰 건물 안 카페는 어긋남
        (예: 포그커피 38m, 컴포즈 대곡역롯데캐슬점 240m). 30곳 중 23곳은 20m 안
      - 893곳이 다른 카페와 같은 좌표 → 숫자 배지 핀 + 누르면 목록 카드
      - "위치가 틀려요" 버튼: 지도를 밀어 가운데 핀에 맞추고 제안 → 구니가 마이 탭 "위치 제안 확인"에서 반영/거절
        규칙: 공개 카페만, 1km 안, 한 사람이 한 카페에 대기 제안 1개. 구니는 "바로 고치기" 가능
   ④ 길찾기
      - 카카오 장소 ID가 있으면 카카오맵 길찾기, 공공데이터 카페는 [카카오맵에서 찾기](이름+시·구 검색) / [핀 위치로]
      - 웹 주소 방식이라 앱 새 빌드 필요 없음
   ⑤ 시험 141개 통과 → main에 합침. 카카오 개발자 콘솔에서 앱 이름 BeanSpot(앱 ID 1614961) 확인
   ⑥ 툭바 (스레드 "툭바 만들기")
      - 프로그램·파일 버튼은 그 프로그램의 원래 아이콘이 자동으로 붙음, 게임 바로가기(.url)도 실행됨
      - 윈도우판을 한 파일 exe → 폴더 방식으로 바꿈(켜는 시간 약 1.9초)
      - 맥판 추가: GitHub의 맥 컴퓨터가 push마다 맥 앱을 묶고 15초 켜 본 화면 사진을 올림
      - 바 밀어 넣기, 자동 숨기기, 켜기·끄기 미끄러지는 효과. 다른 창이 한꺼번에 움직여 깜빡이던 문제 고침
      - 테스터용 묶음: UI\배포\테스터에게_보낼파일 (툭바_윈도우용.zip, 툭바_맥용.zip, 카톡_보낼말.txt)
      - 구니 확정으로 1차 완료, GitHub v1.0 태그. 2차 후보: 테스터 의견, "카톡방 열기" 버튼, 맥 단축키 실제 확인

4. 문제와 해결 과정
   - 카카오 검색 좌표를 그대로 저장하면 규칙 위반 → 공공데이터 + 사람이 핀으로 위치 정하기
   - 공공데이터 좌표가 큰 건물에서 틀림 → 주소 다시 바꾸기는 효과 없음 → 사용자 제안 + 구니 확인
   - 같은 자리 카페 여러 곳이 핀 하나로 겹쳐 보임 → 숫자 배지 + 목록
   - 툭바 맥판에서 바가 왼쪽에서 멈춤 → 설정 창이 숨어 있어 클릭을 막았음 → 창을 보이게 유지
   - 툭바 깜빡임 → 화면 자리 반납·재확보 때 다른 창이 같이 움직였음 → 끝까지 미끄러진 뒤 반납
