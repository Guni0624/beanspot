2. 수정한 파일 상세 (BeanSpotApp)
   ■ src/types/cafe.ts
     - 무엇을: 카페에 hours(영업시간), closedDays(휴무일), phone(전화), menu(대표 메뉴)
       칸을 추가하고, 후기(Review) 모양을 새로 정함
     - 왜: 상세 화면에 보여 줄 정보를 담을 자리가 필요해서
     - 어떻게: 뒤에 ?를 붙여 "없어도 되는 칸"으로 만듦 (hours?: string)
       → 모르는 정보는 비워 두고, 비어 있으면 화면에서 숨김
   ■ src/app/cafe/[id].tsx (카페 상세)
     - 무엇을: 영업 정보 칸, 대표 메뉴 칸, 길찾기 버튼, 후기 목록·평균 별점, 찜 하트
     - 왜: MVP 5번(상세 보강)과 7번(후기 보기)
     - 어떻게: 길찾기는 Linking.openURL("https://map.kakao.com/link/to/이름,위도,경도")
       → 카카오맵 앱이 있으면 앱으로, 없으면 인터넷 창으로 열림
       전화는 Linking.openURL("tel:번호") → 누르면 전화 걸기 화면
       색은 brand.ts(갈색·크림·초록)로 통일
   ■ src/app/cafe-register.tsx (카페 등록)
     - 무엇을: 영업시간·휴무일·전화번호 칸, 대표 메뉴 최대 3개
     - 어떻게: "+ 메뉴 하나 더"를 누르면 메뉴 줄이 늘고, 3개가 되면 버튼이 사라짐
       메뉴 이름이 빈 줄은 저장할 때 빼 버림
   ■ src/app/(tabs)/favorites.tsx (찜 탭)
     - 하트를 누른 카페만 모아 보여 줌. 없으면 "아직 찜한 카페가 없어요" 안내
   ■ src/app/(tabs)/my.tsx (마이 탭)
     - 찜 개수·후기 개수, 내가 쓴 후기 목록, 삭제(한 번 더 "정말 삭제" 확인),
       사진 올리기·카페 등록 바로가기
     - 로그인 전이라 "이 폰에서 쓴 후기 = 내 후기". 로그아웃·탈퇴는 로그인 만들 때 넣음
   ■ src/data/cafe-store.ts
     - 시험 카페 '온기 커피'에 시험용 영업시간·메뉴를 넣어 상세 화면 모양을 볼 수 있게 함

4. 문제와 해결 과정
   - 문제: 자동 시험 중 찜 탭에서 시작 화면(로고)이 다시 뜸
     원인: 시험이 브라우저의 "뒤로 가기"를 써서 앱이 처음부터 다시 켜짐 (폰에서는 안 생기는 일)
     해결: 시험에서 앱 화면의 뒤로 버튼을 누르게 바꿈 → 통과
   - 문제: 시험용 브라우저가 안 켜짐
     원인: 브라우저 설정 폴더가 엉킴
     해결: 새 설정 폴더로 다시 켬
   - 시험 못 한 것: 등록 화면에서 끝까지 등록하기 (웹에서는 지도가 안 떠서 위치를 못 찍음)
     → 폰에서 확인 필요

5. 오늘 배운 개념 (용어 정리)
   - MVP: 사람들에게 처음 써 보게 할 최소한의 첫 버전
   - 서버(백엔드): 앱을 꺼도 정보를 보관해 주는 인터넷 컴퓨터. 빈스팟은 Supabase 무료 요금제 예정
   - 로그인이 서버가 필요한 이유: "이 사람이 누구인지"를 서버가 기억해야 해서
   - 커밋: 고친 코드를 "저장 지점"으로 찍어 두기 (게임 세이브처럼)
   - 푸시: 저장 지점을 GitHub(인터넷 창고)에 올리기
   - 풀(pull): GitHub의 최신 내용을 내 컴퓨터로 받아 오기 (푸시의 반대)
   - 클론(clone): GitHub 창고의 폴더를 처음 통째로 내려받기
   - .env: 비밀 키를 넣는 파일. GitHub에 안 올라가서 새 컴퓨터에는 직접 만들어야 함

6. 자주 쓸 명령어
   - git clone https://github.com/Guni0624/BeanSpotApp.git : 노트북에 앱 폴더 처음 받기
   - git pull : 최신 내용 받기
