1. 작업 흐름
   ① 사용자 등급 (스레드 "사용자 등급")
      - 목적: 활동 등급(후기·사진·등록한 카페 수로 자동 결정). 혜택은 테스트 단계라 나중에, 이번엔 배지만
      - 이름: 시안 여러 개 → 구니 "커피 관련으로" → 열매 → 생두 → 원두 → 에스프레소 → 스페셜티
      - 조건: 열매 가입 즉시 / 생두 후기 1개 또는 사진 3장 / 원두 후기 3개 또는 사진 5장
              에스프레소 후기 10 + 사진 10 + 공개 카페 1곳 / 스페셜티 후기 30 + 사진 30 + 공개 카페 5곳
      - 배지: 빨간 커피 체리·연두 생두·갈색 원두·크레마 잔·원두 메달 (빈스팟 3D 스티커 스타일, 시안 자료 24번)
      - 서버가 숫자를 세서 등급을 정함 → 본인이 등급을 스스로 올릴 수 없음. 숨긴 후기·사진은 안 셈
      - 구니가 Supabase SQL Editor에서 05-levels.sql 실행 → 시험 64/64, 폰 확인 → 커밋·푸시
   ② 지도 탭 (같은 스레드)
      - 추천 3가지 모두 채택: 핀 누르면 아래 카드 / 위에 검색창+카테고리 / 아래 "이 지역 카페" 서랍
      - 시안 3장면으로 먼저 보여 드림 → 구니 승인 → 앱에 적용
      - 구니 아이디어: 인기 카페 다른 색 → 빨간 핀 (기본 기준: 후기 3개 이상 + 평균 별점 4.0 이상)
      - 지도 이동 후 "이 지역 다시 찾기", 카테고리 누르면 맞는 핀만
      - 시험 69/69 → 커밋·푸시
   ③ 툭바 (스레드 "툭바(단축키 버튼 바) 만들기")
      - 이름: 키독(KeyDock) → 해외에 같은 이름이 있어 다시 고름 → 툭바(TookBar)
      - PyInstaller로 TookBar.exe 한 파일로 묶음, 바탕화면 "툭바" 아이콘
      - 3D 버튼 시안 3가지(키캡·젤리·아이콘만 3D) → ② 젤리 선택
      - 올림 모습: 처음엔 티가 안 남 → 더 확실하게 → 너무 셈 → 옅게 → 테두리 조금 밝게 / 누름: 테두리 확실히 빛나게
      - 노트북에서 진짜 마우스로 시험 26개 통과, exe 다시 묶음 (시안 자료 26번)

2. 앱 쪽 바뀐 곳 (BeanSpotApp)
   ■ 지도 탭: 검색창·카테고리 줄, 핀 → 카드(길찾기·자세히 보기), 빈 곳 누르면 카드 내려감, 목록 서랍
   ■ 카카오 지도 부품: 누른 핀 표시, 핀 아래 카페 이름표, 지금 보이는 범위 알려 주기, 내 위치로 이동
   ■ 마이 탭: 닉네임 옆 배지, 초록 막대, "OO까지: 후기 ○개…" 문구
   ■ 카페 상세 후기: 닉네임 옆 작은 배지
   ■ supabase/05-levels.sql: 등급 계산 기능 (지우는 내용 없음)

3. 툭바 쪽 바뀐 곳 (GuNi\UI)
   ■ jelly.py: Pillow(그림 그리는 파이썬 도구)로 젤리 버튼을 그림
   ■ assets\icons\*.png: 3D 아이콘 22개. 예전 이모지 버튼은 자동으로 3D 아이콘으로 바뀜
   ■ launcher.py: 젤리 버튼 연결. launcher.py를 고치면 TookBar.exe를 다시 묶어야 함
   ■ 구니가 만든 버튼(buttons.json)은 그대로 유지

4. 문제와 해결 과정
   - 웹 시험에서는 카카오 지도가 안 떠서 핀·카드는 폰에서만 확인 → 나머지(서랍·목록·검색)는 웹으로 자동 시험
   - SQL 실행 전에는 등급 시험 4개가 실패(모두 열매로 보임) → 구니 SQL 실행 후 64/64
   - 툭바 이름 키독(KeyDock)이 해외 제품과 겹침 → 툭바로. 판매 전에는 특허청(KIPRIS) 상표 확인 필요

5. 오늘 배운 개념 (용어 정리)
   - 바텀 시트(서랍): 화면 아래에서 끌어올리는 판. 지도를 가리지 않고 목록을 보여 줌
   - 서버 계산: 등급처럼 속이면 안 되는 값은 폰이 아니라 서버가 셈
   - exe 묶기(PyInstaller): 파이썬 없이도 더블클릭으로 켜지게 프로그램 하나로 묶는 것
   - 상태별 버튼 그림: 평소·올림(hover)·누름(pressed) 그림을 따로 준비해서 바꿔 끼움
