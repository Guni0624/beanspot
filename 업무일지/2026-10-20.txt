2. 수정한 파일 상세 (BeanSpotApp)
   ■ app.json → app.config.js
     - 무엇을: 지도 키를 파일에 직접 쓰지 않고 .env에서 읽어 오게 바꿈
     - 왜: GitHub에 비밀 키가 올라가지 않게
     - 어떻게: .env(올리지 않는 파일)에 EXPO_PUBLIC_KAKAO_JS_KEY=키,
       .gitignore에 .env 추가, 다른 PC용 안내는 .env.example
   ■ map.tsx, cafe-register.tsx
     - 무엇을: react-native-maps(구글) 대신 카카오 지도 공통 부품 사용
     - 왜: 지도는 카카오로 확정, 두 번 손대지 않도록 기능 전부 옮김
   ■ 홈 화면
     - 무엇을: 새로 만들고 로고 줄을 맨 위에 고정
     - 왜: 내렸다 올렸을 때 로고까지 올라가는 게 어색하다는 구니 의견
   ■ CLAUDE.md
     - 기술 스택 "지도: 카카오 지도", 현재 작업 상태에 오늘 내용

4. 문제와 해결 과정
   - 문제: app.json에 구글 지도 키가 그대로 있었음
   - 해결: .env로 옮기고 첫 커밋을 키 없이 다시 만든 뒤 올림
   - 문제: OneDrive가 "파일 392개 삭제할까요?" 물어봄
   - 원인: 구글 지도 부품(node_modules 안)을 지워서
   - 해결: "모든 항목 삭제" 선택 (유지하면 지운 부품이 되살아남)
   - 문제: 사진에 비밀 키 3개 노출
   - 해결: GitHub 토큰 교체, 카카오는 회사 전용 새 계정으로 옮겨 키 전부 새로 만듦
   - 문제: 카카오 시크릿 KOE010(맞지 않음), KOE004(카카오 로그인 꺼짐) 오류
   - 원인: 키와 시크릿이 서로 다른 앱 것이 섞임
   - 해결: 새 계정에서 업무알림 앱을 새로 만들어 깨끗하게 다시 설정
   - 문제: 앱을 켜면 바로 꺼짐
   - 원인: PC 서버가 아이콘 부품 설치 전 상태를 기억
   - 해결: npx expo start -c 로 새로 시작
   - 문제: 사진 기능 넣은 뒤 오류 화면
   - 원인: 폰에 깔린 빌드에 사진 부품(ExponentImagePicker)이 없음
   - 해결: 누를 때만 불러오게 바꾸고, 새 빌드를 만들어 카톡으로 링크 보냄

5. 오늘 배운 개념 (용어 정리)
   - .env: 비밀 키를 적어 두는 파일, GitHub에는 올리지 않음
   - WebView: 앱 화면 안에 띄우는 작은 웹 창
   - EAS 개발 빌드: 클라우드에서 만든 폰 설치용 앱(APK). 새 부품이 들어가면 다시 만들어야 함
   - Fast Refresh: 코드를 저장하면 폰 화면이 몇 초 안에 저절로 바뀌는 기능
   - Supabase: 앱의 인터넷 창고(서버). 카페·사진·로그인을 저장해 모두가 같이 보게 함
   - 토큰/시크릿: 프로그램이 내 대신 들어가는 출입증과 비밀번호

6. 자주 쓸 명령어
   - npx expo start: 폰에서 앱을 실시간으로 보기 위한 PC 서버 켜기 (켜 둔 채로 두기)
   - npx expo start -c: 기억해 둔 것을 지우고 서버 새로 켜기 (이상할 때)
   - gh secret set 이름 -R Guni0624/beanspot: GitHub 비밀 값 바꾸기
   - git pull: PC beanspot 폴더 작업 전에 최신 내용 받기
