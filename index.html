VISION

카페 데이터 플랫폼

MISSION

사용자와 카페가 함께 만드는
커피 문화를 기록한다.

CORE VALUES

1

신뢰 (Trust)

  • 정확한 정보 우선
  • 별점 조작 없음
  • 리뷰 임의 삭제 불가
  • 커뮤니티 검증 시스템
2

커뮤니티 (Community)

  • 모두가 정보 생산자
  • 리뷰, 사진, 태그 기여
  • 수정 제안 시스템
  • 함께 완성하는 정보
3

사장님과의 동행 (Partnership)

  • 광고주가 아닌 동반자
  • 소통과 성장을 지원
  • 투명한 분석 데이터 제공
  • 공평한 노출 기회
4

데이터 자산 (Data First)

  • 리뷰, 태그, 방문 기록
  • 공간 정보의 정밀 축적
  • 가치 있는 커피 빅데이터
  • 시간이 흐를수록 공고한 신뢰

BeanSpot Manifesto

우리는 커피를 사랑하는 사람들이 함께 만드는 플랫폼을 꿈꿉니다.

우리는 광고보다 신뢰를 우선합니다.

우리는 리뷰를 상품으로 만들지 않습니다.

우리는 사장님을 광고주가 아닌 커뮤니티의 구성원으로 존중합니다.

우리는 시간이 흐를수록 더 정확한 정보를 찾아갑니다.

BeanSpot은 카페를 찾는 앱이 아니라, 커피 문화를 함께 기록하는 플랫폼입니다.

이 프로젝트는 로컬 서버에서 직접 가동해 볼 수 있습니다. 작업 공간은 바탕화면의 beanspot 입니다.
